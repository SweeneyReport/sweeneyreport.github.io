Privacy Policy

Effective date: October 25, 2026

Sweeney Report ("the tool") is a personal desktop tool that publishes short entertainment news videos to its owner's YouTube channel, Sweeney Report. This policy explains which data the tool accesses through the YouTube API Services and what it does with it.

YouTube API Services

The tool uses the YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Data the tool accesses

  • OAuth access token — granted by the channel owner through Google's sign-in screen, with the scopes youtube.upload and youtube.readonly.
  • Channel name (channels.list, own channel only) — displayed once to confirm the tool is connected to the right channel.
  • Upload results (videos.insert) — the ID of each video the tool uploads, so the same video is never uploaded twice.

The tool does not access other users' channels, comments, subscribers, analytics, viewing history, email address or any other personal information.

How the data is used and stored

  • Data is used only to upload the owner's videos to the owner's channel.
  • The access token and the list of uploaded video IDs are stored locally, on the owner's computer only. Nothing is sent to any server other than Google's.
  • No data is sold, shared with third parties, used for advertising or combined with other data.
  • The tool does not use cookies or tracking. This website does not collect any data.

Content of the videos

The videos summarize news already published by media outlets, which are credited in each video description. Photos come from Wikimedia Commons under free licenses and are credited to their authors. The videos contain no personal data about viewers.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page. Locally stored data (token and video IDs) is deleted when access is revoked, and in any case within 30 days on request.

Changes

Any change to this policy will be published on this page with a new effective date.
